# Speech-to-Text

A simple web-based application that converts spoken words into written text using the Web Speech API. This tool offers a hands-free way to take notes or transcribe speech directly in your browser.

## 🔗 Live Demo

[Click here to view the live demo](https://selvaganapathycoder.github.io/Speech-to-Text/)


## ✨ Features

- Real-time speech recognition using the browser’s Web Speech API
- Live transcription displayed as you speak
- Start/stop functionality for speech recognition
- Clean, minimalist UI for ease of use

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
-  Web Speech API
